# Contributing

Add a primary source and complete the fields in catalog.json. State publication year (and different preprint year), exact onboard hardware when supported, training location, model, task, venue, code relationship, and real/simulated evaluation. Mark unknowns. Do not infer deployment from a simulator name or a paper title. Deduplicate by DOI and manuscript lineage. Supply metric year/category/source for any quartile claim. Avoid unsupported performance comparisons across different sensors, tracks, power modes and input sizes. Do not upload copyrighted PDFs without permission.
